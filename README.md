# Katalog

## Opis projektu
Aplikacja desktopowa wykonana w C# i Avalonia. Umożliwia przeglądanie katalogu, wyświetlanie szczegółów oraz dodawanie nowych pozycji.

## Funkcje
- Lista pozycji z tytułem, rokiem i oceną.
- Wyświetlanie szczegółów wybranej pozycji.
- Formularz dodawania nowych pozycji.
- Walidacja danych.
- Przycisk „Policz”, który zlicza pozycje w pliku tekstowym.



Format: `tytuł;rok;ocena`

## Zasady projektu
Zasady zapisane w pliku `AGENTS.md`.
